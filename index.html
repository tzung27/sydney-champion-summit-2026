01

FY27 Windows Commercial Device 的主要 KPI 與成長指標是什麼？

Revenue、Windows 11 refresh、Copilot+ PC attach、M365 Copilot attach 的優先順序

+

預期答案

  • Windows 11 commercial refresh 仍是第一優先。Windows 10 已在 2025/10/14 結束支援，仍有大量企業裝置在用 ESU 撐著，換機量（units）與 Windows 11 Pro 商務機出貨是核心指標。
  • AI PC / Copilot+ PC mix：新出貨中 AI PC、Copilot+ PC 的占比，以及搭 Intel Core Ultra（含 vPro）的商務機占比。
  • Attach rate：每台裝置附帶的雲端服務，例如 M365 Business Premium / E3 / E5、Intune、Windows 365、M365 Copilot 授權。微軟越來越用「裝置帶動雲」來衡量通路價值。
  • Revenue / Pipeline：通路營收與可追蹤的 pipeline，常以 Partner Center 申報的 deal 或 campaign 成效計算。

02

Copilot+ PC 在企業市場最適合的實際銷售情境是什麼？

哪些工作負載真正需要 NPU；AI PC 與 Copilot+ PC 的區隔

+

先釐清定義

  • AI PC：泛指有 CPU + GPU + NPU 的電腦（如早期 Core Ultra Series 1），NPU 約 10–11 TOPS。
  • Copilot+ PC：微軟認證規格，NPU 40 TOPS 以上、記憶體 16 GB 以上、儲存 256 GB 以上。Intel 方面為 Core Ultra 200V（Lunar Lake）與 Core Ultra Series 3（Panther Lake）等。
  • Copilot+ PC 才有的 Windows 功能：Recall（預覽）、Click to Do、語意化 Windows 搜尋、即時字幕翻譯、Windows Studio Effects、設定裡的 AI agent。

最適合的銷售情境

  • 大量線上會議的業務、主管：Studio Effects（背景模糊、眼神校正、降噪）在 NPU 跑，不吃 CPU、省電，續航更長。
  • 跨國團隊 / 客服：即時字幕與翻譯可離線執行，不經過雲端。
  • 知識工作者：用自然語言搜尋本機檔案、Click to Do 快速摘要或改寫。
  • 資料不能上雲的產業（金融、醫療、政府、製造）：本機推論（on-device AI）可降低資料外流疑慮，ISV 也能用 Windows ML / Foundry Local 在 NPU 上跑自家模型。
  • 行動辦公：Lunar Lake / Panther Lake 的電池續航是很直接的賣點，不必先談 AI。

可追問

"Which commercial workloads show measurable ROI on the NPU today, and do you have customer references in Asia we can reuse?"哪些商務工作負載在 NPU 上已有可量化的效益？亞洲有沒有可以借用的客戶案例？

對展碁的意義

話術要分兩層：所有商務機都該是 Windows 11 + Core Ultra + vPro（安全與管理），重度會議、行動、資料敏感的族群再升級 Copilot+ PC。這樣不會因為 AI 功能還不夠成熟而卡住整體換機。

Windows 10 EOS 後，Distributor 應如何帶動企業換機？

拆分 SMB、Enterprise、Education、Government

+

現況

Windows 10 已於 2025/10/14 終止支援。企業版 ESU（延伸安全性更新）第一年在 2026/10 到期，第二年價格加倍、第三年再加倍，最長到 2028/10。現在正好是第二年續約的決策點，是推換機最好的時機。

分市場打法

市場痛點建議方案
SMB沒有 IT 人員、預算有限、怕資安事件Windows 11 Pro 商務機 + M365 Business Premium（Intune、Defender for Business）打包、分期或租賃，強調「ESU 的錢拿來換新機更划算」

Windows 裝置如何與 Microsoft Cloud 做組合銷售？

Device + M365 Business Premium + Intune + Defender + Copilot

+

建議的三層組合

層級裝置雲端服務賣點
基本安全Windows 11 Pro + Core Ultra 商務機M365 Business Premium（含 Intune、Defender for Business、Entra ID P1，最多 300 人）一張授權搞定 Office、管理與資安
現代管理Core Ultra vPro 商務機+ Autopilot 部署、Windows Autopatch、（大型客戶）M365 E3 / E5開箱即用、遠端管理、自動更新

銷售動作

  • 以「每人每月」來報價（裝置分期 + 授權），讓客戶比較的是總持有成本，而不是單機價格。
  • 經銷商端提供一份標準 Bundle SKU 與報價範本，降低組合銷售的門檻。
  • 用 Autopilot 示範「新機寄到員工手上、登入就完成設定」，是最容易讓 IT 主管買單的 Demo。

技術重點速記

會前建議熟悉的主題，每項一兩句重點，現場聽講時可當對照。

Windows 11 Pro / Enterprise

Pro 適合 SMB；Enterprise（E3 / E5 訂閱）多了進階安全與管理功能。硬體需 TPM 2.0 與受支援的 CPU，是舊機無法升級、必須換機的主因。

Copilot+ PC 與 NPU

NPU 40+ TOPS、16 GB RAM、256 GB 儲存。NPU 專跑持續性 AI 工作（視訊特效、字幕、本機模型），比 CPU / GPU 省電。

Intel Core Ultra

Series 2（200V Lunar Lake）與 Series 3（Panther Lake）NPU 達 Copilot+ 規格，主打續航與整合 GPU 效能。

Intel vPro

商務平台認證：硬體層安全（Intel Hardware Shield）、遠端管理（AMT，可在開機前或系統當機時維修）、穩定的平台生命週期。

Microsoft 365 Copilot

雲端 AI 助理，整合 Word、Excel、Outlook、Teams 與企業資料（Microsoft Graph）。與 Copilot+ PC 是兩件事：一個是授權服務，一個是裝置規格，可分開賣也可組合。

Intune · Autopilot · Autopatch

Intune 管裝置與 App 政策；Autopilot 讓新機零接觸部署；Autopatch 自動排程 Windows 與 Office 更新。

Defender · Hello · BitLocker

Defender for Endpoint / Business 做端點防護；Windows Hello 以臉部或指紋免密碼登入；BitLocker 整碟加密，筆電遺失時資料不外洩。

Windows 365 Cloud PC

在 Azure 上的雲端電腦，以每人每月計費。適合外包、短期專案、BYOD 與分公司，也可搭 Windows 365 Link 精簡終端。

串起 Outlook、Teams、SharePoint、OneDrive 等資料的服務，M365 Copilot 依此理解企業內容。
Entra ID原 Azure AD
微軟的雲端身分驗證與存取管理服務，負責登入、MFA 與條件式存取。
MFAMulti-Factor Authentication

Windows 與 AI PC

EOSEnd of Support
終止支援。Windows 10 已於 2025/10/14 EOS，之後不再提供免費安全更新。
ESUExtended Security Updates
延伸安全性更新，付費才能繼續取得 Windows 10 安全修補。企業版最多 3 年，價格逐年加倍。
Windows 11 Pro / Enterprise
Pro 是商務基本版；Enterprise 透過 E3 / E5 訂閱提供，多了進階安全與管理功能。
AI PC
泛指內建 NPU、能在本機執行 AI 工作的電腦，規格門檻沒有統一定義。
Copilot+ PC
微軟認證的 AI PC 等級：NPU 40 TOPS 以上、16 GB RAM、256 GB 儲存，才能使用 Recall、Click to Do 等專屬功能。
NPUNeural Processing Unit
神經網路處理器，專門執行 AI 推論，比 CPU / GPU 更省電，適合長時間跑的 AI 工作。
TOPSTera Operations Per Second
每秒兆次運算，用來衡量 NPU 的 AI 運算能力。
On-device AI本機 AI
AI 模型在電腦本機執行，資料不必上傳雲端，延遲低、隱私較好。
Recall
Copilot+ PC 功能，定期擷取畫面並在本機建立索引，讓使用者用自然語言找回看過的內容。企業可用政策控管。
Click to Do
Copilot+ PC 功能，對畫面上的文字或圖片直接執行 AI 動作，例如摘要、改寫、去背。
Windows Studio Effects
由 NPU 執行的視訊效果：背景模糊、眼神校正、自動取景、語音降噪。
Windows ML / Foundry Local
讓開發者在 Windows 本機的 NPU / GPU 上執行 AI 模型的平台與工具。
Secured-core PC
符合微軟最高硬體安全規範的電腦，從韌體到作業系統層層防護。
TPM 2.0Trusted Platform Module
主機板上的安全晶片，存放加密金鑰，是 Windows 11 的必要條件。
BitLocker
Windows 的整碟加密功能，筆電遺失時資料無法被讀取。
Windows Hello
用臉部辨識、指紋或 PIN 登入 Windows，取代密碼。

Windows Autopatch
由微軟自動排程與分批推送 Windows、Office、驅動程式更新的服務。
Defender for Endpoint / Business
微軟的端點防護與偵測回應（EDR）。Business 版是給 SMB 的精簡版，含在 Business Premium 中。
Windows 365Cloud PC

Windows 365 Link
微軟推出的精簡型終端設備，開機直接連到 Windows 365 雲端電腦。
BYODBring Your Own Device
員工使用自己的裝置辦公，常用 Intune App 保護或 Windows 365 控管公司資料。
